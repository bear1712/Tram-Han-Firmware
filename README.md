# Tram Han Soldering Station Firmware

## OTA Update Instructions

### For Users:
1. Go to System Settings → System Info → Check Update
2. If new version available, select Update Firmware
3. Wait for download and automatic reboot

### For Developers:
- Firmware files are in `/firmware/` folder
- Update `firmware.version` when releasing new version
- Source code in `/src/` folder
